| 环  cycle                                                    |
| ------------------------------------------------------------ |
| 环，不是圆。是规则闭合后，玩家又回到同一个选择。 环是**时间**：存档即读档，死亡即重来，每次轮回，世界记得，玩家不记得。 环是**空间**：走廊首尾相接，地图没有出口，终点是起点的另一面。 环也立足**系统**：资源回流，生态咬合，你修好的东西，正在别处制造代价。 环可指向**叙事**：因果首尾相衔，玩家走到结局，才听懂开场的伏笔。 环在**玩家维度**：失败不是清零，是迭代。每一局，都在给下一局留刻度。 环不是重复。是闭合，每次让规则偏一度。本次Panda Game Jam，主题是环 Cycle。 别画一个圆。做一个，让玩家想再走一圈的环。 |

### 背景

和花小时候因为多重因素，分裂出了两个人格。一个是妹妹，一个是哥哥。而游戏的九张图分别是处于两个人格的视角看的。处于哥哥视角下的地图是2D俯视角解谜，而妹妹视角下的地图则是横板解谜。

### 剧情

#### Opening（P = 玩家）

P：

你见过鬼吗？呃，我是说，你有过被附身的经历吗？别误会，我并不是要呃，宣传一些神神鬼鬼的东西。但是——好吧。

我本来也不相信鬼的存在。但自从我上了大学以后，有些我解释不清的事发生在身边。

比如，明明没有喝酒却在第二天早上起来完全记不清昨晚发生了什么。比如经常回过神来发现就在手边的东西被移到了别处。再或者明明刚刚才接了一杯水端起杯子却发现是空的……之类的。

我承认我平时确实不太小心啦……但，这些事显然不是我迷糊才发生的。毕竟，总不会有人在我上课的时候趁我不注意偷偷把我的水喝光再，呃，放回原处吧……

不过这个世界上，据说有很多怪人存在。说不定会有那种喜欢偷喝别人的水的人也说不定，不过在我这十八年的人生中，我是没见过那种人……

嗯，言归正传，总之这些事逐渐发展到了让我不能忽视的地步。我的朋友也说，我有时会突然像变了个人似的，而且根据观察，大概有两个人经常出现。

一个是七岁左右的小女孩，另一个是十二岁左右的小男孩。他们分别说是我的妹妹和哥哥。

我可不记得我的父母曾经给我生过哥哥或妹妹，更何况他们早就已经离婚了。

呃，妹妹说不定有可能，如果他们在我不知道的地方复合了……什么的。嗯，果然还是不太可能。

我仔细回想母亲的面貌，却发现已经想不起来了。算下来在她和父亲离婚后，我已经八年没见过她了。

我似乎没法从脑子里揪出他们离婚的理由，那些琐事一直在脑中的迷雾中隐藏着自己的身形。

不过我经常忘事啦，这也是我的一大特点。呃，说不定这些被我遗忘的记忆，说不定其实真的被鬼魂给夺走了？

我把这些想法告诉朋友之后，她们都说我脑子有问题。

这点我倒是不否认啦，再加上我心里或许隐隐觉得，我的忘性大不是天生的，或许其中藏着某些惊天阴谋。

说不定我其实是穿梭时空在不同世界执行秘密任务的特工，但在一次任务之后不小心被敌人给抓住。敌人在我身上进行了惨无人道的实验，我记不住事便是那是的后遗症……

我把这些想法告诉朋友之后，她们又说我脑子有问题。

我知道啦，也没必要说两遍吧……

总之在她们的建议下，我预约了心理医生。

（转场）
